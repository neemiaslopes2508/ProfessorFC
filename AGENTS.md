# Professor FC

- O projeto se chama Professor FC.
- É um jogo web single-player de gerenciamento de futebol.
- O jogador terá uma carreira como treinador.
- O mundo inicial será baseado na temporada real de 2026.
- É obrigatório usar jogadores reais, clubes reais, competições/ligas reais e valores reais como base inicial.
- O mundo evoluirá através da simulação depois do início da carreira.
- A carreira deverá suportar até 50 temporadas.
- A arquitetura deverá permitir expansão futura para novas divisões, competições, clubes e países.
- A stack planejada é React + TypeScript.
- A lógica do jogo deverá ser independente da interface.
- O projeto deve priorizar modularidade, performance, manutenção e compatibilidade de saves.
- Não adicionar dependências desnecessárias.
- Não realizar grandes alterações arquiteturais sem justificar.
- Antes de implementar uma funcionalidade, consultar `docs/GDD.md`, `docs/TECHNICAL_SPEC.md` e `docs/DECISIONS.md`.
- Nunca considerar apenas "o código compilou" como validação suficiente. Executar testes adequados.
- O desenvolvimento será incremental.
- Não implementar funcionalidades ainda não definidas na documentação sem registrar/explicar a decisão.
